HTML is the standerd code used to organize and structure the content on a web page. IT stands for Hyper Mark Up Language. It is like the skeleton for a website so the browser knows how to display all the text, images, etc.

CSS

CSS stands for Cascading Style Sheet. CSS is used to make the visuals, desgins, and layout for a web page. It determines how the HMTL elements look.

JavaScript

JavaScript is the code used to make the interactice elements of a web page. It does pop-up animations, animations, respond to clicks, etc. It serves as a core technology of the WWW

Bootstrap

Bootstrap is a web design framework used to build websites or the initial startup code that boots a computer. It is like the orerating system or software application for a more complex system. It helped build responsive web sites quickly.
